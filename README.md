# AI Bias Detection in Hiring Systems (Adult Census Dataset)

## Overview
This project analyzes potential bias in AI-driven hiring decisions using the Adult Census Income dataset. The goal is to evaluate whether predictive models treat demographic groups fairly.

## Objectives
- Train a machine learning model to predict income level
- Evaluate fairness across gender groups
- Identify potential bias in predictions
- Visualize results using Power BI

## Tools Used
- Python (Pandas, Scikit-learn, Fairlearn)
- Jupyter Notebook
- Power BI
- GitHub

## Key Findings
- The model shows variation in selection rates across gender groups
- Potential bias exists in prediction outcomes
- Fairness metrics were used to quantify disparities

## Dashboard
Power BI dashboard includes:
- Hiring overview
- Bias analysis
- Governance insights

## Dataset
Adult Census Income Dataset:
https://archive.ics.uci.edu/dataset/2/adult
